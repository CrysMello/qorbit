01 · Início
Primeiro acesso ao Qorbit
⬡ Qorbit

Acesse o Qorbit pelo navegador na URL fornecida pelo administrador (ex: http://localhost:8080). Você será redirecionado automaticamente para a tela de login.

🔑 Login
1
Informe seu e-mail e senha
Use as credenciais criadas pelo administrador ou no cadastro.
2
Clique em Entrar
Se MFA estiver ativo, você será direcionado para validação de código.
3
Você chega ao Dashboard
A visão geral do sistema exibe métricas, execuções recentes e status.
Esqueceu a senha? Clique em "Esqueci minha senha" na tela de login. Um e-mail de recuperação será enviado automaticamente.
📝 Criar nova conta
1
Clique em Criar conta
Na tela de login, acesse o formulário de registro.
2
Preencha nome, e-mail e senha
A senha deve ter no mínimo 8 caracteres, letras e números.
3
Confirme e acesse
Após registro, faça login normalmente.
🔐 Autenticação de dois fatores (MFA)
Se o administrador exigir ou você quiser maior segurança, configure o MFA após o login.
→ Acesse Perfil → Configurar MFA
→ Escaneie o QR code com Google Authenticator ou Authy
→ Guarde os 8 códigos de backup em local seguro
→ A cada login, informe o código de 6 dígitos do app

02 · Dashboard
Visão geral — Dashboard
⬡ Qorbit

O Dashboard é a tela inicial após o login. Ela consolida o estado atual do seu ambiente de testes em tempo real.

📊 Métricas principais (topo)
→ Elementos cadastrados — total na biblioteca POM
→ Casos de teste — total criados
→ Execuções — total de execuções realizadas
→ % de sucesso — taxa média de steps que passaram
⚡ Execução em andamento
Quando um teste está rodando, o Dashboard exibe em tempo real:
✓ Barra de progresso com porcentagem concluída
✓ Step atual sendo executado
✓ Contadores de passou / falhou em tempo real
Dica: Deixe o Dashboard aberto durante a execução. Ele atualiza automaticamente via WebSocket, sem precisar recarregar a página.
📋 Histórico de execuções recentes
Lista as últimas execuções com:
CampoSignificado
CONCLUÍDOExecução finalizada normalmente
ERROExecução encerrada com falha crítica
EM ANDAMENTOTeste ainda em execução
AGUARDANDONa fila para iniciar
🧭 Menu lateral (sidebar)
Navegue entre os módulos clicando nos ícones ou nomes no menu esquerdo:
→ Dashboard · Elementos · Casos · Suites
→ Gravar · Nova Execução · Histórico
→ Evidências · Gerar Código · Plugin IA

03 · Elementos
Biblioteca de Elementos (Page Object Model)
⬡ Qorbit

A Biblioteca de Elementos é o catálogo dos componentes da interface que seus testes vão interagir. Cadastre aqui os campos, botões e links da aplicação testada.

🔍 Captura automática por URL
1
Clique em Capturar Elementos
Informe a URL da página a ser mapeada.
2
O Qorbit abre o navegador e varre a página
Detecta inputs, selects, botões, links e outros elementos interativos.
3
Revise e ative os elementos encontrados
Elementos aparecem com status PENDENTE. Ative os que serão usados.
Recomendação: Antes de criar casos de teste, sempre construa a biblioteca da URL alvo primeiro.
✏️ Adicionar elemento manualmente
Use quando a captura automática não encontrar o elemento desejado.
CampoDescrição
Nome lógicoEx: "Campo Email", "Botão Salvar"
PáginaTela ou módulo onde fica o elemento
Tipo seletorCSS, XPATH, ID, NAME, LINK_TEXT
SeletorEx: #btn-login
StatusATIVO (disponível) ou PENDENTE
🔎 Filtrar e gerenciar
✓ Busca por nome ou página
✓ Filtro por status (ATIVO / PENDENTE)
✓ Editar seletor quando o elemento mudar
✓ Remover elementos desatualizados

04 · Casos de Teste
Criar e gerenciar casos de teste
⬡ Qorbit
📝 Criar novo caso de teste
1
Clique em + Novo Caso
Preencha: nome, módulo e URL alvo do teste.
2
Adicione os passos (steps)
Cada passo é uma ação: NAVEGAR, CLICAR, PREENCHER, SELECIONAR, VALIDAR, etc.
3
Para cada passo: escolha ação, elemento e valor
O sistema gera o texto Gherkin automaticamente.
4
Salve o caso
Ele recebe um código automático: CT-01, CT-02, etc.
Dica: Reordene os passos arrastando as linhas. Use ↑ ↓ para mover steps.
⚡ Ações disponíveis nos passos
AçãoO que fazValor
NAVEGARAbre URL no navegadorURL completa
CLICARClica em um elemento—
PREENCHERDigita em campo de textoTexto a digitar
SELECIONAREscolhe opção em dropdownTexto da opção
VALIDARVerifica texto na telaTexto esperado
LIMPARApaga conteúdo de campo—
WAITAguarda N segundosSegundos (ex: 2)
🔍 Visualizar em Gherkin
Ao visualizar um caso, os passos são exibidos em linguagem Gherkin:
Scenario: Login com sucesso Given que o usuário navega para "/login" When preenche "Campo Email" com "user@email.com" And preenche "Campo Senha" com "senha123" And clica em "Botão Entrar" Then valida que "Mensagem Boas-vindas" contém "Olá"

05 · Gravação
Gravar teste — fluxo rápido
⬡ Qorbit

A gravação permite capturar um fluxo de teste executando-o normalmente no navegador — sem precisar criar steps manualmente.

🎬 Como gravar um teste
1
Acesse Gravar Teste no menu lateral
2
Informe a URL inicial e clique ▶ Iniciar Gravação
O Chrome abre automaticamente na URL informada.
3
Execute o fluxo normalmente no navegador
Clique, preencha campos, navegue entre páginas. O Qorbit captura tudo em tempo real.
4
Clique em ■ Parar Gravação
Os passos gravados aparecem na lista com preview em Gherkin.
5
Dê um nome ao caso e clique em Salvar
O caso é criado automaticamente com todos os passos gravados.
✅ O que é capturado automaticamente
✓ Cliques em botões e links
✓ Texto digitado em campos de input
✓ Seleções em dropdowns (nativos e customizados)
✓ Navegações entre páginas (URL)
✓ Nome lógico sugerido automaticamente por IA (se configurada)
✏️ Revisar após gravação
Após salvar, acesse Casos de Teste para:
→ Remover passos desnecessários
→ Adicionar passos de VALIDAR
→ Reordenar a sequência
→ Ajustar valores gravados
⚠️ Atenção: Senhas digitadas durante a gravação são capturadas como valor do campo. Revise os passos antes de compartilhar o caso de teste.

06 · Suites
Organizar e executar suites de teste
⬡ Qorbit

Suites agrupam múltiplos casos de teste para execução em conjunto. Use para organizar por módulo, sprint ou fluxo de negócio.

📦 Criar nova suite
1
Clique em + Nova Suite
Informe o nome da suite (ex: "Regressão Sprint 14") e escolha uma cor de identificação.
2
Adicione casos de teste à suite
Selecione os casos (CT-01, CT-02, etc.) que compõem este grupo.
3
Salve e execute quando precisar
Clique em ▶ Executar Suite para rodar todos os casos em sequência.
Organização sugerida: Crie uma suite por módulo da aplicação (Login, Cadastro, Checkout) e uma suite "Regressão Completa" com todos os casos críticos.
⚙️ Gerenciar composição da suite
→ Adicionar ou remover casos a qualquer momento
→ Reordenar a sequência de execução
→ Um mesmo caso pode estar em várias suites
→ Alterar cor para identificação visual
📤 Exportar suite
✓ Baixe todos os casos da suite como projeto ZIP
✓ Pronto para rodar em CI/CD (Maven + Selenium + Cucumber)
✓ Inclui arquivo de feature Gherkin gerado automaticamente
📊 Resultado da suite
Após execução, o Dashboard mostra o resumo por caso: PASSOU FALHOU com taxa de sucesso geral da suite.

07 · Execução
Configurar e executar testes
⬡ Qorbit

Acesse Nova Execução no menu para configurar e rodar seus testes em 4 etapas.

🔧 Passo 1 — Configuração geral
CampoOpções / Descrição
URL alvoURL base da aplicação sendo testada
NavegadorChrome · Firefox · Edge
Timeout por stepSegundos antes de considerar falha (padrão: 10s)
RetentativasQuantas vezes tentar antes de falhar definitivo
🔑 Passo 2 — Autenticação (opcional)
→ Cookie: cole os cookies de uma sessão ativa (F12 → Application)
→ Usuário/Senha: o Qorbit faz login automaticamente antes de executar
→ Token Bearer: informe o token JWT para APIs autenticadas
📋 Passo 3 — Selecionar testes
Marque os casos ou suites que deseja executar nessa rodada.
→ Filtre por módulo ou nome
→ Selecione casos individualmente ou a suite inteira
→ A ordem de execução segue a ordem selecionada
▶ Passo 4 — Confirmar e executar
Revise o resumo e clique em ▶ Executar.
✓ O navegador abre automaticamente
✓ Acompanhe o progresso no Dashboard em tempo real
✓ Screenshots são capturadas a cada step
Execuções presas? Se uma execução ficar em "AGUARDANDO" por muito tempo, acesse Histórico → Limpar execuções presas.

08 · Evidências
Visualizar e exportar evidências de execução
⬡ Qorbit

Toda execução gera capturas de tela automáticas a cada passo. Acesse o módulo Evidências para analisar o que aconteceu.

📸 Acessar evidências de uma execução
1
Acesse Evidências no menu lateral
2
Selecione a execução desejada
Use o seletor no topo para filtrar por ID, URL ou data.
3
Filtre por status
PASSOU exibe capturas de sucesso · FALHOU exibe as falhas
4
Clique em uma captura para ampliar
O lightbox exibe a imagem em tela cheia com detalhes do passo.
📋 Informações em cada evidência
CampoConteúdo
Número do stepEx: Step 3 de 8
Ação executadaCLICAR, PREENCHER, VALIDAR...
Elemento alvoNome lógico do elemento
StatusPASSOU ou FALHOU
Motivo da falhaCausa em linguagem natural (quando falha)
ScreenshotCaptura do estado da tela no momento
📦 Exportar evidências
✓ Clique em ⬇ Baixar ZIP para exportar todas as capturas
✓ O ZIP contém imagens organizadas por step
✓ Ideal para anexar em relatórios de bug ou chamados
Diagnóstico inteligente: Em vez de "ElementNotFoundException", o Qorbit mostra: "Elemento fora da área visível — scroll necessário antes da interação". Isso reduz horas de triagem.

09 · Exportação
Gerar código para CI/CD
⬡ Qorbit

O módulo Gerar Código exporta seus casos de teste como um projeto Maven pronto para rodar em pipelines de CI/CD.

📤 Como exportar o código
1
Acesse Gerar Código no menu lateral
2
Selecione os casos de teste a exportar
Filtre por módulo ou selecione manualmente.
3
Configure as opções avançadas
Veja as opções disponíveis na coluna ao lado.
4
Clique em ⚙ Gerar e depois ⬇ Baixar ZIP
Para CI/CD: Ative "Driver headless" para executar sem abrir janela do navegador. Essencial para ambientes de servidor.
⚙️ Opções de exportação
OpçãoQuando usar
GitHub ActionsGera workflow YAML para rodar no GitHub CI
Driver headlessExecução sem interface gráfica (servidores)
WebDriverManagerDownload automático do driver (recomendado)
📁 Estrutura do ZIP gerado
projeto-selenium.zip ├── pom.xml # Maven + Selenium + Cucumber ├── src/test/ │ ├── java/steps/ │ │ └── StepDefinitions.java │ └── resources/features/ │ └── testes.feature # Gherkin └── .github/workflows/ └── testes.yml # GitHub Actions
Rodar localmente: Descompacte o ZIP e execute mvn test na pasta do projeto. Requer Java 17+ e Maven instalados.

10 · Plugin de IA
Configurar e usar o Plugin de Inteligência Artificial
⬡ Qorbit

O Plugin de IA conecta o Qorbit a qualquer API de linguagem (DeepSeek, Mistral, Claude, OpenAI, etc) para funcionalidades avançadas.

🔧 Configurar o Plugin
1
Acesse Plugin de IA no menu lateral
2
Preencha Endpoint, Modelo e API Key
A API Key deve ser definida via variável de ambiente QORBIT_AI_API_KEY pelo administrador.
3
Clique em Testar Conexão
O sistema valida se a API responde corretamente.
4
Ative e salve a configuração
As funcionalidades de IA ficam disponíveis em todo o sistema.
🤖 Funcionalidades disponíveis
✦ Auto-naming: IA sugere nomes descritivos para elementos capturados automaticamente (ex: "btn_123" → "Botão Confirmar Compra")
✦ Diagnóstico de falhas: IA explica em português por que um passo falhou, com sugestão de correção
✦ Auto-healing: quando um elemento muda, IA sugere estratégias alternativas de localização
📊 Monitoramento de uso
→ Total de requisições enviadas à API
→ Taxa de sucesso das respostas
→ Logs estruturados de cada interação
⚠️ Segurança: Nunca insira a API Key diretamente no formulário. Configure sempre via variável de ambiente QORBIT_AI_API_KEY para evitar exposição nas configurações.

💡 Dicas de produtividade
✓ Use a Gravação para criar testes complexos rapidamente — depois ajuste com validações
✓ Mantenha a Biblioteca de Elementos atualizada — elementos com status PENDENTE não funcionam nos testes
✓ Sempre adicione steps de VALIDAR no final de cada fluxo para confirmar o resultado esperado
✓ Nomeie os casos de forma descritiva: "Login - email inválido" é melhor que "CT-05"
✓ O aprendizado do Qorbit melhora com o uso — execute os mesmos casos repetidamente para ganhar precisão
