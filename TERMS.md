# Termos de Uso — Qorbit

*Última actualização: Abril 2026*

---

## 1. Uso Permitido

O Qorbit é uma ferramenta de automação de testes destinada a:

- Equipas de QA e desenvolvimento de software
- Automação de testes funcionais em ambientes controlados
- Uso educacional e aprendizado de automação de testes

---

## 2. Uso Responsável do Selenium Stealth

O Qorbit inclui funcionalidades de Selenium Stealth para contornar
detecção básica de automação. Esta funcionalidade deve ser utilizada:

✅ **Permitido:**
- Testes em ambientes de desenvolvimento e homologação
- Testes em sistemas que você possui ou tem autorização explícita
- Testes de regressão em pipelines CI/CD internos

❌ **Não permitido:**
- Testes em sistemas de terceiros sem autorização
- Contornar medidas de segurança de forma maliciosa
- Scraping de dados em violação dos termos de serviço de terceiros
- Qualquer actividade que viole leis locais ou internacionais

---

## 3. Uso de Inteligência Artificial

A integração com IA no Qorbit é:

- **Opcional** — o sistema funciona completamente sem IA
- **Configurável** — o utilizador escolhe e configura o provedor de IA
- **Transparente** — os prompts enviados à IA são visíveis no código

O Qorbit não é responsável pelo conteúdo gerado por APIs de IA de terceiros
(Groq, OpenAI, DeepSeek, etc.). O utilizador é responsável por cumprir os
termos de uso do provedor de IA escolhido.

---

## 4. Credenciais e Segurança

- Chaves de API devem ser guardadas de forma segura
- Não faça commit de chaves de API em repositórios públicos
- O Qorbit não armazena nem transmite chaves de API para servidores externos
- As chaves são usadas apenas localmente para chamadas às APIs configuradas

---

## 5. Limitação de Responsabilidade

O Qorbit é fornecido "tal como está", sem garantias de qualquer tipo.
Os autores não são responsáveis por danos causados pelo uso inadequado
da ferramenta.

---

## 6. Preparação para SaaS (futuro)

Esta secção será expandida quando o Qorbit evoluir para um modelo SaaS,
incluindo: controlo de credenciais, isolamento de execução, planos de
subscrição e política de dados.

---

*Ao utilizar o Qorbit, você concorda com estes termos.*
